# ⛧ PHANTOMS EYE — KALI LINUX TOOL

**PHANTOMS EYE** is a Python-based cybersecurity information and network reconnaissance toolkit with a terminal interface inspired by Kali Linux.

⛧ **IP Deep Lookup** — Collects publicly available IP information, including geolocation estimates, ISP, ASN, reverse DNS, and network registration data.

⛧ **URL Deep Search** — Analyzes publicly accessible website information, including DNS records, HTTP headers, redirects, TLS certificates, metadata, and security headers.

⛧ **DNS Lookup** — Retrieves available DNS records for a domain.

⛧ **Domain Information** — Retrieves publicly available domain registration and nameserver information.

⛧ **HTTP Header Analysis** — Inspects server responses and security-related HTTP headers.

⛧ **TLS Certificate Information** — Displays available certificate details for HTTPS connections.

⛧ **Network Utilities** — Provides additional diagnostic and information-gathering functions.

⛧ **Terminal Interface** — Features a black CMD-style interface, yellow/orange accents, numbered tools, and Kali-inspired ASCII artwork.

⛧ **Python-Based** — Designed to run from a Windows command prompt with a simple startup script.

## ⚠️ Disclaimer

PHANTOMS EYE is intended for educational purposes, defensive cybersecurity, and authorized testing. It uses publicly available information and standard network requests. Only analyze systems you own or have permission to test. Geolocation results are approximate and may not identify an exact physical location.
